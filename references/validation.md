# 发布验收范围 · 2026-11-04

测试使用独立目录、独立端口及合成旅行记录，没有读取或覆盖作者个人浏览器数据。实景配图使用已核对许可的公开图片；测试行程用于联动验证，不是完整旅行推荐。

| 模块 | 本轮实际验证 | 边界 |
| --- | --- | --- |
| 初始化与升级 | 启动器及升级回归：端口、存储标识、生成内容、配置与额外文件保留；自改冲突停止；写入失败回滚 | 文件快照不包含浏览器存储，升级前仍需整份导出 |
| 交通住宿与规划 | 浏览器从空数据载入三城七天；未生成订单或到访；原生侧栏、日期与城市联动 | 测试规划没有真实订单；既有订单冲突与合并由回归测试覆盖 |
| 每日行程 | 浏览器切换城市和日期，编辑备注、刷新、恢复备份后仍保留 | 无日期、跨年、同城返回及海外元数据有自动化测试，本轮未逐一浏览器重走 |
| 目的地与 My Pick | 原生图卡显示；导入地点、My Pick、日程共用关联 ID；来源事实、时区、人数、行李元数据回归 | 自动查证资料与照片不属于编译器能力；每次生成仍需研究与目视检查 |
| 地点地图 | 默认 Leaflet 的贵阳真实搜索、候选预览、手动选点、确认、刷新和恢复；底图加载；390 × 844 窄屏无横向溢出 | 高德及海外搜索主要通过模拟回归，本轮未验证每个国家、POI 或网络 |
| 足迹、心愿、照片与回放 | 复用省市、世界聚合、状态分离、无日期/部分日期/完整日期、照片关联与回放自动化测试；新规划零虚构到访 | 本轮重点是发布版通用能力，没有重新遍历此前每张 Demo 的全部主题状态 |
| 数据与备份 | 浏览器导出 8.8 MB，预览、恢复、刷新成功；三张配图与原文件 SHA-256 一致，日程修改和手动位置保留 | 备份摘要“照片 / 样片”统计回忆媒体；攻略内嵌配图随攻略记录备份，不计入此数字 |
| 失败处理 | 自动化覆盖重复恢复、损坏备份、配额不足、并发修改、五份恢复快照及升级写入失败 | 使用模拟故障，没有实际耗尽电脑磁盘或浏览器配额 |

可复现的回归命令（Node.js 18+、Python 3.10+）：

```sh
node --test tests/*.test.cjs assets/app/tests/*.test.cjs
python3 -m unittest discover -s tests
python3 -m unittest discover -s assets/app/tools/tests
```

Windows、Linux、手机真机和受限网络环境未完成整套浏览器验收。公共地图与天气服务可能限流或缺少资料；不能据此承诺每位用户与作者私有数据版本的内容完全相同。
