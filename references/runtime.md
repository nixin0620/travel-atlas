# 运行与地图

## 环境

基础服务使用 Python 3.10+ 标准库，启动无需 Node 构建步骤、付费 AI API 或数据库服务器。生成目的地内容包需 Node.js 18+，使用标准库，无 npm 依赖。现代浏览器需允许 localStorage 和 IndexedDB。

macOS 上的小红书长图识别复用 Swift/Vision，需可用的 `swiftc`（Xcode Command Line Tools）。其他系统仍可使用手动正文导入与应用基础功能；长图 OCR 不支持。Pillow 为可选依赖，用于图片尺寸与保守缩略图处理，缺少它不影响应用启动。Linux/Windows 尚未做整套浏览器验收。

启动后必须保持服务进程运行。若页面提示连接被拒绝，先确认启动进程和端口，而不是清除数据。

## 地图

中国与世界足迹概览使用随包的地图数据。具体地点地图默认采用现有 OpenStreetMap/Leaflet 与 Photon 路径，需要联网，公共服务可能限流，不能保证所有中文 POI 都能匹配。保留地图选点和位置修改入口。

希望使用高德时，将工作目录中的 `.env.example` 复制为 `.env.local`，填写使用者自己的配置：

```dotenv
TRAVEL_AMAP_JS_KEY=
TRAVEL_AMAP_SECURITY_JSCODE=
TRAVEL_AMAP_WEB_KEY=
```

JS API Key 和安全密钥配套使用；Web 服务 Key 是可选 POI 后端。文件不加入 Git。安全密钥由本地代理使用，浏览器仅接收 JS API Key。重启服务后生效。

## 数据

工作目录只包含应用文件；用户输入、上传照片与恢复快照主要保存在当前浏览器。启动器会记住成功启动的端口；下次使用同一目录且省略 --port 时沿用它。旧目录尚未保存端口时需核对原地址。持续使用同一浏览器及完整地址（127.0.0.1 与 localhost 也不同）。清理浏览器数据、隐私模式或更换浏览器会影响可用性，因此需要通过「设置 → 数据与备份」导出。整份 JSON 备份当前上限为 80 MB，超出时会报错，不会静默丢掉照片。

初始化使用独立 `travel-atlas-public-v1` 命名空间，个人数据为空，不读取作者的目录、旧数据或密钥。导出包含现有旅行、攻略、My Pick、日程及照片；恢复前由现有机制保留快照，最多五份。手动下载的备份不受清理影响。

`--demo` 使用另外的 `travel-atlas-demo-v1` 命名空间，默认目录 `travel-demo`、端口 8791；个人版默认 `my-travel`、8790。脚本拒绝把个人目录转为示例目录，或将示例目录当作个人目录启动。重复启动不会重新写入示例。示例导出仍含演示安排，不应恢复到个人工作副本。

## 首版范围

内置云南编辑示例用于快速体验。个性化目的地由 agent 按 create-trip.md 调研并生成结构化内容，build-trip.cjs 绑定到现有指南、日程与地图；不依赖订票或酒店记录来创建规划日期。此脚本不自动查资料、保证网络可用或代替图片/POI 核实。已有订单优先保留，跨日期冲突需核对。

公开仓库中的风景图为原创示例 SVG 插画，未包含作者的旅行照片或未核实再分发许可的景点照片。用户上传的照片按原有相册布局展示。

GitHub 存放代码和安装包。完整功能需要本地 Python 服务，不能仅通过 GitHub Pages 静态托管获得攻略导入与地图代理能力。
