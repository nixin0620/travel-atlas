# 首次使用

只在首次初始化或用户反馈“效果不同”时阅读。安装、使用引导由 Codex 处理，不让用户理解工作目录、数据结构或复制多段提示词。

## 示例旅行

按 SKILL.md 使用 `--demo`。公开固定示例为 2027-03-12 至 2027-03-21：西双版纳 3 晚、普洱 3 晚、玉溪 1 晚、昆明 2 晚，共 10 天。日期仅为演示，不随用户电脑日期伪装成真实订单。所有住宿名称含“示例住宿 · 未预订”，无票号、价格或预订信息；已去过、个人回忆和照片不预填。

打开交通住宿与每日行程，确认城市和日期联动。用户想试交互时，可在现有目的地指南选一个地点加入 My Pick，再安排到示例日期，刷新验证；不需要先调研整趟云南旅行。插画的作用是占位，不能保证与作者的实拍图片效果相同。

## 个人旅行

简短询问：“想去哪里、什么时候出发？有现成行程或攻略也可以直接发我。” 不重复询问上下文已经提供的信息。可以先整理攻略，不强制日期、人数或照片齐全。

- 有备份：从“设置 → 数据与备份”读取摘要，按现有覆盖确认和快照流程恢复。不要直接改写存储绕过确认。
- 有真实交通住宿：按用户信息录入；“应用到行程”后检查城市和日期，再安排地点。不填虚构酒店来解锁日程。
- 有攻略：通过“目的地指南”导入正文或支持的公开链接，核对地点归属，再加入用户选择的 My Pick。受平台限制时让用户提供正文即可，不反复请求同一失效链接。
- 只有目的地或规划需求：按 [目的地内容工作流](create-trip.md) 调研、配图并编译原生规划。无需订单即可建立日期；日期未知可按 D1…Dn 安排。禁止另外拼接文字网页。
- 有照片/回忆：按用户指定的城市保存。不要从给出的图片猜测用户已经到访，也不要自动点亮心愿城市。

使用现有保存与备份能力，保留地点和日程关联。首次完成一个实际操作后给出链接及下一步即可，不把简单安装扩展成一次全站改造。

## 交付与下次打开

交付中保留实际工作目录和完整访问地址。下次继续使用同一目录时不要再加默认 `--port 8790`：启动器会沿用保存的端口。旧版目录没有 port 字段时，应先从原启动命令或用户已有浏览器地址核对，而不是猜测。`127.0.0.1` 与 `localhost`、不同端口、不同浏览器的数据相互独立。

明确区分“应用已安装”和“旅行已生成”。安装只提供可运行的界面；生成完成还需确认内容已载入、图片实际显示、日期/相对天数与地点联动、刷新后保留。目录文件不是用户数据备份，首次使用后说明「设置 → 数据与备份」的导出入口。

## 效果不同的检查顺序

1. 确认根目录 `SKILL.md`、`assets/app`、`scripts/start.py` 来自本仓库，而不是旧版手册生成 skill 或重新生成的页面。
2. 确认当前服务器实际工作目录与所检查文件一致。脚本复用旧目录，不会自动升级；先备份再处理版本差异。
3. 查看是否空数据。空白个人版显示“目的地待添加”属于预期；示例版应有四个城市和十天。
4. 区分图片差异与代码差异：安装模板只含示例插画，作者私图不在仓库；个性化生成必须调研并绑定有许可的实景图。检查是否执行 build-trip.cjs、是否载入规划，不能以安装完成代替内容完成。
5. 地图错误单独排查网络与可选高德配置。无需付费 AI API；不要把改模型或提高推理预算当成安装修复。
6. 使用真实浏览器检查并明确未通过项。保留用户端口和数据，不用清空存储掩盖问题。

## 更新已有个人目录

先确认当前服务的真实工作目录、浏览器和端口，从「设置 → 数据与备份」导出整份备份。下载新版仓库后，停止该工作目录的服务（不停止其他服务），运行：

```sh
python3 /absolute/path/new-travel-atlas/scripts/update.py --workspace /absolute/path/my-travel
python3 /absolute/path/new-travel-atlas/scripts/start.py --workspace /absolute/path/my-travel
```

更新器只替换可识别的原版应用文件，保留生成的旅行内容、工作目录标识、端口、`.env.local` 和额外文件；先建立同级文件快照，再开始写入。检测到自改代码、链接目录、示例目录或未知版本时中止，不写入任何应用文件。遇到冲突应对比处理，不能删除标记或改端口绕过。

文件快照不包含浏览器中的 localStorage/IndexedDB，因此不能代替前面的整份导出。更新后沿用原地址并刷新，检查自己的城市、照片、My Pick、日程和编辑保存。首次从旧目录升级未记录端口时，显式使用核对过的原端口，不能猜测。不要把作者的个人项目或另一位使用者的内容复制进公开仓库。
